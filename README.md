# ScholarAI

An AI-assisted web app that helps students prepare for MCA and MBA entrance exams (NIMCET, Karnataka PGCET-MCA, MBA entrances) while building small daily habits.

Most exam-prep tools focus only on content and ignore the harder part: staying consistent for months. Most habit apps have nothing to do with a student's actual goals. ScholarAI puts both in one account, with a Default / Exam switch.

**Default Mode**: two small Comfort Zone tasks each day, one fiction and one non-fiction book pick (with a one-line reason), and a streak that grows when both tasks are done.

**Exam Mode**: choose an exam, then work through subjects and units. Each unit has three quiz rounds (two fixed, one generated by AI on your weak spots), YouTube videos played in the app with watch % saved, and an AI tutor for doubts. A unit is complete when you score 60% or more in any round.

## Stack

React 19 + Vite + TypeScript, React Router, Tailwind, Zod, Vitest · Supabase (Postgres + RLS, Auth with email and Google, Edge Functions) · Gemini (student's own key) · YouTube Data API + IFrame Player · Cloudflare Workers.

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # Vitest
npm run lint
npm run build
```

`.env` (not committed) needs `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`.

## Set up Supabase (once)

```bash
supabase login
supabase link --project-ref <your-project-ref>
supabase db push                                 # tables, security rules, starter content
supabase secrets set YOUTUBE_API_KEY=<key>       # typed in your terminal, never in code
supabase functions deploy ai
supabase functions deploy gemini-key
supabase functions deploy unit-videos
```

In the Supabase dashboard → Authentication → URL Configuration, add your local and deployed site URLs to **Redirect URLs** (needed for Google sign-in and email confirmation).

## Deploy (Cloudflare Workers)

```bash
npx wrangler login
npm run deploy
```

## Folder guide

| Folder | What lives there |
| --- | --- |
| `src/pages/` | One file per screen |
| `src/components/` | Shared UI pieces (app frame, progress bar, video player…) |
| `src/services/` | The only code that talks to Supabase or the AI |
| `src/lib/` | Small pure helpers (dates, streak, quiz scoring), covered by tests |
| `supabase/migrations/` | Database tables, security rules and starter content |
| `supabase/functions/` | Server code: `ai` (all AI calls), `gemini-key`, `unit-videos` |
| `supabase/functions/_shared/aiRouting.ts` | Which AI answers which task |
